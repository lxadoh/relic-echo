# 《旧物回响》分支叙事 · 搪瓷缸打样剧本

状态:打样稿,待玩家兼产品负责人试玩确认;确认后按此模板批量改写其余 7 件旧物。
完整文本以游戏内为准(`js/data.js` 搪瓷缸条目),本文档负责说明结构与设计意图。

## 一、玩法变化

原版:3 屏正文 + 结尾 1 个轻选择,约 2 分钟读完。
分支版:14 个剧情节点、3 个选择点、3 条结局线、1 个隐藏彩蛋;单次通关约 4–6 分钟,集齐全部结局与彩蛋需要 3 次不同走法。

故事框架不变:你在店里拿起物件,回忆展开。区别在于,回忆里的关键抉择这次由你来做——你替十九岁的李广顺做决定,也替他承担决定的滋味。

## 二、分支结构

```
frame 店内取缸(接入点)
  └─ n2 1978年冬夜·发现裂纹 ──┬─【选择A】报告老周 ── a1 师徒连夜返工,王科长记恨
                              ├─【选择B】私藏裂纹件 ── b1 被保卫科查获,老周担责
                              └─【选择C】装作没看见 ── c1 批次出厂伤牛,匿名信补救
                                        │(三线合流)
  mid 名额之争·评审会前夜 ──────┬─【选择A】会上和盘托出 ── a2 老周押上工龄作证
                              ├─【选择B】写成集体功劳 ── b2 复写纸三份,不撕破脸
                              └─【选择C】让贤给老周 ──── c2 老周划掉自己名字推徒弟
                                        │(殊途同归:李广顺得奖)
  award 颁奖礼堂·领缸 ────────┬─【选择A】endA 传承结局(师徒碰缸)
                              ├─【选择B】endB 亲情结局(病床+粮票)──→ egg 隐藏彩蛋
                              └─【选择C】endC 岁月结局(锁门+四十年)
```

第一幕三条线成本不同:A 得罪人但问心无愧,B 连累恩师被扣工资,C 保全自己却背上半年愧疚。第二幕是"怎么把这件事说出口"的三种处世方式。第三幕决定这只缸最初为谁而亮——也是它最终被寄卖到店里的那条暗线。

## 三、选择点设计

每个选项带一个性格倾向标签(游戏内以小字显示在选项下方,不剧透走向),标签只为让玩家在按下去之前,知道自己在选一种什么样的活法。

## 四、转折点(起承转合)

1. **裂纹(起)**:夜班手电的光斑里一道头发丝细的裂纹,合格章鲜红——冲突的种子。
2. **返工/担责/召回(承)**:三条线各自把"代价"做实,人物动机全部落地。
3. **名额之争(转)**:事故线收束,冲突转移到人与人的台面上,郑卫东与王科长登场。
4. **颁奖分岔(合)**:大喇叭念名是全故事的情绪顶点,之后玩家亲手决定这只缸的去处。

## 五、结局与彩蛋

- **结局A · 传承**:两只搪瓷缸轻轻一碰,"缸是空的,人得是满的"。
- **结局B · 亲情**:病床前父亲就着缸口喝温水;母亲把半市斤粮票塞进缸底。
- **结局C · 岁月**:雪夜锁车间门,四十年装过什么,缸身上的磕碰都记着——呼应"现在"缸口的掉瓷。
- **隐藏彩蛋(仅结局B可触发,一次性)**:四十八年后,你在店里把粮票对着灯翻过来,背面有父亲瞒着全家的铅笔字。第一次走到这里才会出现;回响集中不计数,留给发现它的人。

重玩激励:回响集卡片显示"回忆结局 x / 3",新结局解锁时有提示;三个结局走完,玩家自然理解粮票、掉瓷、红字各自的来历。

## 七、工程说明

- `js/data.js`:搪瓷缸条目改为 `start` + `nodes` 结构;每个节点含 `text`,可选 `img`(剧情插画)、`next`(下一节点)、`prompt`+`choices`(选择,含 `label`/`tag`/`to`)、`ending`(结局标记)、`eggTo`(彩蛋链)、`finishLabel`。其余 7 件暂保持原线性结构,两套结构在引擎中共存。
- `js/game.js`:新增分支引擎(节点导航、中途选择、跳转打字)、结局收集(`oe_endings` 存档)、彩蛋一次性触发;线性故事的旧逻辑不受影响。
- `index.html` / `css/style.css`:阅读页为全屏插画(双层交叉淡入:同图深模糊铺底层 + 全屏插画层,竖屏 cover / 宽屏 contain,插画入场带轻微落定动效;无插画的节点沿用上一幅场景,故事开场用物件图压暗充当背景);选项区固定在页面底部文档流中,正文区独立滚动,二者互不遮挡;选项按钮支持倾向标签;回响集卡片显示结局计数。
